# Frozen regression fixtures

These outputs were produced by the earlier Python prototype before the C++ implementation. They preserve numerical provenance and are not regenerated by the C++ test command.

- `transport_same_order.csv`: 36 transport calculations used by `qtransport audit`.
- `dynamics.json`: collision and Gram matrices, transport, relaxation and projected shear curves used by the test suite.
- `hilker_comparison.json`: the optional sound application's frozen predictions.

The C++ implementation is self-contained and does not execute Python. Agreement with these fixtures checks implementation consistency, not independent physical validity. Analytical prefactors, the separately reduced Wu integrals, conservation, matching and refinement provide complementary checks. Published experimental data are kept separately under `references/hilker2022/` with their own attribution.
