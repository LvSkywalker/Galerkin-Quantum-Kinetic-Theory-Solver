\begin{abstract}
This note describes a reproducible C++17 implementation of transport and
linear relaxation for normal classical, Bose and Fermi gases. Matched
Sonine--Laguerre bases, rotational reduction of collision integrals from eight
to five variables and Gaussian quadrature yield finite positive-definite
systems for viscosity and thermal conductivity. Five first-profile states
agree with a separately evaluated variational reference within $0.0031\%$;
basis and quadrature refinements assess the separate discretization errors.
The same collision matrices also generate homogeneous linear relaxation and
a projected transverse-wave calculation. An optional final application couples
the computed Bose transport coefficients to normal-phase thermodynamics to
compare sound damping with published measurements. The implementation is in
C++17. The scope is deterministic linear kinetic theory, with a separate
assessment of the additional assumptions in the sound application.
\end{abstract}
