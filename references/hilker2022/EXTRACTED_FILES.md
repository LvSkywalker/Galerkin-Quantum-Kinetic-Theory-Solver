# Extracted CSV files

`Figure_4bc_exp.csv` and `Figure_4bc_th.csv` are byte-for-byte copies of the members with the same names in the original `HilkerSoundData.zip`, kept with their comments, column names, units and the source-data discrepancy described in `docs/HILKER_ANALYSIS.md`. They are extracted so the program can read them directly.

Authors, DOI and the CC BY 4.0 license are in `ATTRIBUTION.json`. Everything under `results/hilker/` is derived from these data and is not original experimental data.
