# CSV extraction for the C++ reader

`Figure_4bc_exp.csv` and `Figure_4bc_th.csv` are byte-for-byte copies of the correspondingly named members of the original `HilkerSoundData.zip`. They retain the comments, original column names, units and source-data discrepancy. They are included so the C++ program does not need a ZIP-library or Python extraction step at runtime.

Original authors, DOI and CC BY 4.0 license are in `ATTRIBUTION.json`. The original archive and readme remain unchanged. C++ outputs under `results/cpp/hilker/` are derived calculations and figures, not original experimental data.
